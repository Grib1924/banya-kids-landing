# Детский лендинг творческой мастерской «Баня»

Адаптивная посадочная страница для родителей детей 4–13 лет. Структура и тексты перенесены из файла «Страница 1», визуальная система — из брендбука.

## Запуск

1. Установите Node.js 22 или новее.
2. Выполните `npm install`.
3. Для разработки: `npm run dev`.
4. Для проверки сборки: `npm run build`.

Основной код находится в `app`, изображения — в `public/assets`.

## Tilda

Готовый автономный комплект находится рядом, в папке `tilda-static`. Там есть `index.html`, `styles.css`, `script.js`, код для блока T123 и папка изображений.

Формы сейчас демонстрационные. Перед запуском их нужно подключить к Tilda Forms, CRM или webhook.
